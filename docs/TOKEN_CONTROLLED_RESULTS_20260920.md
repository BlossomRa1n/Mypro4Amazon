# 四组 token 精排受控验证：最终优化总结与结果分析

## 结论

在本次未来窗口数据、固定候选池和 3 epoch 预算内，**SVD 用户均值初始化是退化的主要来源；semantic_concat 本身没有显示退化，在随机用户初始化下还有小幅收益。** 这修正了此前把 context/dense 重编码列为首要嫌疑的判断。

四组全部从头训练，没有把旧 DIN checkpoint、旧两组 token 实验或 smoke 当作控制组。本阶段实验、开发/测试评估、服务器全量协议审计和本地证据读取均已完成。第一阶段到此结束，不追加多 seed、context/dense 消融或其他训练。

## 正式结果

每组按同一 10 万开发用户的 HR@5 选取最早达到最高值的 epoch，再评估同一 10 万测试用户。HR@5 是至少命中一个未来目标的用户比例。表内指标为百分数；后续差值单位为**百分点**。

| 组 | 用户初始化 | 测试 HR@5 | 测试 NDCG@5 | 最佳 epoch |
|---|---|---:|---:|---:|
| DIN | 随机 | 4.469% | 2.05334% | 1 |
| DIN | SVD 均值 | 4.061% | 1.82990% | 3 |
| semantic_concat | 随机 | **4.585%** | **2.11169%** | 1 |
| semantic_concat | SVD 均值 | 4.075% | 1.83130% | 3 |

| 受控对比（前者−后者） | ΔHR@5 [95% 区间] | ΔNDCG@5 [95% 区间] | 新增/丢失命中用户 |
|---|---:|---:|---:|
| concat_random − din_random | **+0.116** [+0.017, +0.212] | **+0.05834** [+0.01211, +0.10458] | 1,271 / 1,155 |
| concat_svd − din_svd | +0.014 [−0.090, +0.118] | +0.00141 [−0.04777, +0.05058] | 1,371 / 1,357 |
| din_svd − din_random | **−0.408** [−0.520, −0.298] | **−0.22345** [−0.27817, −0.16873] | 1,362 / 1,770 |
| concat_svd − concat_random | **−0.510** [−0.619, −0.401] | **−0.28038** [−0.33522, −0.22555] | 1,282 / 1,792 |

随机用户初始化时，semantic_concat 相比 DIN 的 HR@5 相对提升约 **2.60%**，净多命中 116 名测试用户。两项指标的用户配对区间均高于零。SVD 用户初始化时，两个结构没有被本次区间区分开；这不等于证明它们完全等价。

HR 区间使用 10,000 次配对 multinomial bootstrap；NDCG 区间使用逐用户差值的正态近似。均条件于本次固定模型，不包含重训练 seed 的波动，也未做多重比较校正。

## 为什么此前 token 尝试失败

**首先，用户初始化不是一个无害的小改动。** 在 DIN 内单独换成 SVD 用户均值，HR 下降 0.408 个百分点；在 concat 内同样切换，下降 0.510 个百分点，NDCG 也同步下降。两条独立的结构内对照都指向这一训练配置改动。

**其次，原对比混合了结构变化和用户初始化变化。** 本次从 DIN_random 到 concat_svd 的净差为 −0.394 个百分点。可以沿两条受控路径核算：

- 先换结构、再换用户初始化：`+0.116 − 0.510 = −0.394`。
- 先换用户初始化、再换结构：`−0.408 + 0.014 = −0.394`。

这说明不能把原先“token 模型落后随机用户初始化 DIN”的差距全部计入 token 结构。原凌晨差距为 −0.417 个百分点，数值接近，但旧实验还混有共同初始参数和选模差异，不能声称已精确分解旧差距的每一部分。

**最后，训练 loss 更低并不代表未来排序更好。** 随机用户两组第一轮即取得最佳开发 HR；SVD 两组一直到第三轮才达到各自最佳值，仍低于随机用户组。

| 组 | 三轮开发 HR@5 | 三轮 BPR loss |
|---|---|---|
| din_random | 4.625% → 4.535% → 4.581% | 0.088642 → 0.032014 → 0.011397 |
| din_svd | 3.954% → 4.146% → 4.216% | 0.031046 → 0.013968 → 0.006368 |
| concat_random | 4.688% → 4.519% → 4.608% | 0.090901 → 0.029983 → 0.010821 |
| concat_svd | 3.919% → 4.055% → 4.161% | 0.032139 → 0.013717 → 0.006194 |

本阶段定位到的是“使用训练商品 SVD 均值初始化用户”这一改动在当前训练预算下的负面效果，没有进一步测定尺度、用户表示相似性或梯度路径中的具体机制，也不能断言更长训练预算下仍相同。context/dense、LayerNorm 和 Mixer 的单独作用没有在这四组中被隔离；不能继续把它们称为已经证实的主因。

历史 raw-slice 是等价重构，已有等价验收，不属于失败的结构实验。历史五路 token 同时改过商品分支混合、投影和旁路，不能用本次结论替它们逐项定因。关于旧实验的证据见 [归因复核](TOKEN_RANKER_ATTRIBUTION_20260920.md)。

## 控制条件与校验

固定 data_id 为 `754d426bc41ff19907bd31b3f139e3150d09cc13a746924fecc42e562a92b158`；未来窗口为用户严格较早的 80% 前缀预测全部未来正反馈后缀，开发和测试用户不相交。四组共用 75 候选、RRF、ItemCF 300 邻居、180 天半衰期、权重 `[2.0, 1.0, 0.7, 0.05]`、训练 seed 42、初始化 seed 424242、3 epoch、4 负样本及同一开发/测试记录。

商品 SVD 四组相同；随机用户表在两个结构间相同，SVD 用户均值表也相同。品牌、品类、DIN attention、兼容排序头参数和 buffers（含首层 bias）显式复制并核验 SHA-256。仅首层 weight 因输入为 1358/1536 维而不能复制。同架构两组除用户表外的初始 state 完全一致。

建模结束后重置训练 RNG，四组初始 CPU/CUDA RNG 指纹相同。跨结构额外 dropout 调用仍会改变后续 mask，不能宣称每一层 mask 完全相同。三轮各 **4,731,648 个有效训练样本**的顺序与合法负例完成全量重建，每轮另以四组实际 PrefixDataset 的 128 个分散样本核验；三轮共重建 14,194,944 个训练样本、56,779,776 个负例 ID。实际候选 ID、历史排除、pool_hit、逐用户 uid/position 均与四组最终数组相符。

顺序/负例校验属于冻结代码与配置的确定性重建，不是训练时逐批保存的原始 trace。部分依赖源码在运行中补采，其时间与 SHA-256 已保留；不把它们冒称为启动前快照。

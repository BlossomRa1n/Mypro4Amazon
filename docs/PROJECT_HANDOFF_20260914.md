# 项目交接与下一步计划

更新时间：2026-09-19（Asia/Shanghai）

## 当前项目

这是一个基于 Amazon Reviews 2023 五个品类的“召回 + 精排”推荐系统，目标是为用户输出 Top-5 商品。当前代码同时保留历史实验和一套修复后的可复现基线，不能混用两套结果。

权威基线入口是 `code/run_baseline.py`。它修复了训练目标泄漏、训练集外 SVD/统计、PAD/UNK 编码、完整已见历史过滤、候选去重回填、断点恢复和指标计算等问题。相关协议见 `docs/BASELINE_PROTOCOL.md`。

## 指标调整

业务目标是“未来窗口内 Top-5 准确率”，因此主指标应改为未来窗口 HR@5：每个用户按时间取前 80% 正反馈作为历史，后 20% 的所有唯一正反馈商品作为目标集合，Top-5 命中任意目标即成功。单目标 leave-two-out HR@5/NDCG@5 继续作为辅助诊断。

`code/future_window_data.py` 已修正为真正调用 80/20 切分，相关测试和服务器正式规模运行均已通过。主指标使用用户前 80% 正反馈历史、后 20% 唯一商品目标集合，Top-5 命中任意目标即成功。旧的单目标结果只能作为历史辅助，不能与未来窗口主指标直接比较。

## 下一步

1. 按同一开发用户集合继续做候选预算、ItemCF 衰减和融合权重的单变量筛选。
2. 按候选池 HR@100 与 DIN 条件 HR@5 拆解召回和精排瓶颈，补充分品类、历史长度和商品热度分组指标。
3. 只有开发集稳定通过后，才重新训练并评估 raw-slice token、RankMixer、MIND/HSTU 等结构方案。
4. 所有新实验都必须保存协议、data_id、checkpoint 身份和完整目标集合；测试集只用于最终确认。
5. 服务器空间目前紧张，清理只能针对明确的临时文件，不能删除原始数据、checkpoint、结果 JSON 或归档。
